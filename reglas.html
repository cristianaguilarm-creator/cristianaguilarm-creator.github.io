Reglas Matemáticas

Suma

  • Conmutativa: a + b = b + a
  • Asociativa: (a + b) + c = a + (b + c). | (IA)
  • Elemento neutro: a + 0 = a
  • Inverso aditivo: a + (-a) = 0
  • Suma de matrices: A + B es posible si tienen la misma dimensión. | (IA)
  • Suma de series: Σ (aₙ + bₙ) = Σ aₙ + Σ bₙ. | (IA)
Ejemplos de suma:
  • Conmutativa: 2 + 3 o 3 + 2 => 5
  • Asociativa: (1 + 2) + 3 = 1 + (2 + 3) = 6
  • Elemento neutro: 7 + 0 = 7
  • Inverso aditivo: 5 + (-5) = 0
  • Suma de matrices: [1 2] + [3 4] = [4 6]
  • Suma de series: Σ(1 + 2) = Σ1 + Σ2. | (IA)

Resta

  • Resta inversa de la suma: a - b = a + (-b)
  • No es conmutativa: a - b ≠ b - a. | (IA)
  • Resta de cero: a - 0 = a
  • Resta de polinomios: se restan coeficientes de términos semejantes.
  • Resta de vectores: u - v = u + (-v). | (IA)
Ejemplos de resta:
  • Inversa de suma: 8 - 3 = 8 + (-3) = 5
  • No conmutativa: 8 - 3 = 5, pero 3 - 8 = -5
  • Resta de cero: 9 - 0 = 9
  • Polinomios: (x²+3x) - (x²-x) = 4x
  • Vectores: (2, 5) - (1, 3) = (1, 2). | (IA)

Multiplicación

  • Conmutativa: a · b = b · a
  • Asociativa: (a · b) · c = a · (b · c)
  • Elemento neutro: a · 1 = a
  • Distributiva sobre suma: a · (b + c) = a·b + a·c
  • Producto escalar: u·v = |u| |v| cos(θ). | (IA)
  • Producto de matrices: AB existe si columnas de A = filas de B. | (IA)
Ejemplos de multiplicación:
  • Conmutativa: 3·4 o 4·3 = 12
  • Asociativa: (2·3)·4 = 2·(3·4) = 24
  • Elemento neutro: 5·1 = 5
  • Distributiva: 2·(3+4) = 2·3 + 2·4 = 14
  • Escalar: (2,0)·(0,3) = 6·cos(90°) = 0
  • Matrices: [1 2]·[3;4] = [11]

División

  • a ÷ b = a · (1/b), siempre que b ≠ 0
  • No es conmutativa: a ÷ b ≠ b ÷ a
  • División entre 1: a ÷ 1 = a
  • Fracción algebraica: (a/b) ÷ (c/d) = (a/b) · (d/c)
  • División sintética: método rápido para dividir polinomios.
Ejemplos de división:
  • Inversa: 6 ÷ 2 = 6 · 1/2 = 3
  • No conmutativa: 6 ÷ 2 = 3 y 2 ÷ 6 = 1/3
  • División por 1: 7 ÷ 1 = 7
  • Fracción algebraica: (x/2) ÷ (3/x) = x²/6
  • Sintética: dividir x²+3x+2 entre x+1 da x+2

Potencias

  • a⁰ = 1 cuando a ≠ 0
  • a¹ = a
  • a^{m} · a^{n} = a^{m+n}
  • (a^{m})^{n} = a^{m·n}
  • (a·b)^{n} = a^{n} · b^{n}
  • a^{-n} = 1/a^{n}
  • a^{p/q} = q√(a^{p}), cuando a ≥ 0
  • Regla de los logaritmos: log(a^{b}) = b · log(a). | (IA)
Ejemplos de potencias:
  • a⁰: 5⁰ = 1
  • a¹: 7¹ = 7
  • a^{m}·a^{n}: 2²·2³ = 2⁵ = 32
  • (a^{m})^{n}: (2²)³ = 2⁶ = 64
  • (a·b)^{n}: (2·3)² = 6² = 36 = 2²·3²
  • a^{-n}: 2^{-3} = 1/8
  • a^{p/q}: 8^{2/3} = 4
  • Logaritmos: log(2³) = 3·log 2

Polinomios

  • Un polinomio es una suma de términos con potencias enteras no negativas.
  • Clasificación por grado: grado 0 (constante), grado 1 (lineal), grado 2 (cuadrático), etc.
  • Suma y resta de polinomios: se combinan términos semejantes.
  • Multiplicación: se multiplica cada término de un polinomio por cada término del otro.
  • Factorización: extracción de factor común, productos notables, trinomio cuadrado perfecto, diferencia de cuadrados.| (IA/YO)
  • Teorema Fundamental del Álgebra: un polinomio de grado n tiene n raíces complejas contadas con multiplicidad.
Ejemplos de polinomios:
  • Definición: x² + 3x + 2
  • Grado: x² + 1 es grado 2
  • Suma: (x²+2x)+(x²-x)=2x²+x
  • Multiplicación: (x+1)(x+2)=x²+3x+2
  • Factorización: x²-1=(x-1)(x+1)
  • Teorema Fundamental: x²-1 tiene raíces ±1

Operaciones combinadas

  • Orden de operaciones: primero paréntesis, luego exponentes, después multiplicación y división, y al final suma y resta.
  • PEMDAS en inglés o «PEMDAS» equivalente en español. | (IA)
  • Si hay paréntesis dentro de paréntesis, resuelve de adentro hacia afuera.
  • Para expresiones con radicales y fracciones, normaliza primero si es posible.
  • Para polinomios, aplica el mismo orden a cada término y combina términos semejantes al final.
Ejemplos de operaciones combinadas:
  • Orden: 2 + 3·4 = 2 + 12 = 14
  • Exponentes: 2 + 3² = 2 + 9 = 11
  • Paréntesis: (2 + 3)·4 = 20
  • Dentro de paréntesis: (1 + (2 + 3))·2 = 12
  • Polinomios: (x + 3m)² + (3m + x)(3m - x)
  • Radicales: 2 + √9 = 5
  • Fracciones: 1 + 2/3 = 5/3

Geometría

  • Área del rectángulo: base · altura
  • Área del triángulo: (base · altura) / 2
  • Área del trapecio: (base mayor + base menor) · altura / 2
  • Perímetro del círculo: 2 · π · radio
  • Área del círculo: π · radio²
  • Volumen del prisma: área de la base · altura
  • Volumen del cilindro: π · radio² · altura
Ejemplos de geometría:
  • Rectángulo: 5·2 = 10
  • Triángulo: (4·3)/2 = 6
  • Trapecio: (5+3)·2/2 = 8
  • Perímetro círculo: 2π·3 ≈ 18.85
  • Área círculo: π·3² = 28.27
  • Volumen prisma: 6·4 = 24
  • Volumen cilindro: π·2²·5 ≈ 62.83

Trigonometría | (IA)

  • Seno: sin(α) = cateto opuesto / hipotenusa
  • Coseno: cos(α) = cateto adyacente / hipotenusa
  • Tangente: tan(α) = sen(α) / cos(α)
  • Identidades básicas: sin²(α)+cos²(α)=1
  • Fórmulas de ángulo doble: sin(2α) = 2 sinα cosα
  • Fórmulas de suma y diferencia: sin(a ± b) = sin a cos b ± cos a sin b
  • Relaciones trigonométricas en el círculo unitario y funciones inversas.
Ejemplos de trigonometría:
  • sin(30°)=1/2
  • cos(60°)=1/2
  • tan(45°)=1
  • Identidad: sin²30°+cos²30°=1
  • Ángulo doble: sin(2·30°)=sin60°=√3/2
  • Suma: sin(30°+60°)=sin30°cos60°+cos30°sin60°
  • Círculo unitario: punto (cosθ, sinθ)

Álgebra

  • Resolver ecuaciones consiste en despejar la incógnita usando operaciones inversas.
  • Multiplicar o dividir ambos lados de una ecuación por el mismo número mantiene la igualdad.
  • Suma o resta el mismo valor en ambos lados para simplificar la ecuación.
  • Ecuación cuadrática: ax² + bx + c = 0 y fórmula general x = (-b ± √(b²-4ac)) / (2a).
  • Sistemas de ecuaciones: usar sustitución, eliminación o matrices.
  • Matrices: operaciones de suma, multiplicación, determinante y transpuesta.
Ejemplos de álgebra:
  • Despejar: 2x+3=7 → x=2
  • Multiplicar ambos lados: x/2=3 → x=6
  • Sumar ambos lados: x-4=5 → x=9
  • Cuadrática: x²-5x+6=0 → x=2, 3
  • Sistema: x+y=3, x-y=1 → x=2, y=1
  • Matrices: [1 2]+[3 4]=[4 6]

Expresiones algebraicas

  • Una expresión algebraica puede incluir números, letras y operaciones.
  • Término semejante: misma variable con el mismo exponente.
  • Para simplificar, combina términos semejantes y aplica las propiedades de las operaciones.
  • Productos notables: (a+b)² = a² + 2ab + b², (a-b)² = a² - 2ab + b², (a+b)(a-b) = a² - b².
  • Racionalizar fracciones: eliminar raíces del denominador mediante multiplicación adecuada.
Ejemplos de expresiones algebraicas:
  • Expresión: 2x + 3
  • Términos semejantes: 2x + 3x = 5x
  • Simplificar: 4x + 2x - x = 5x
  • Producto notable: (x+1)² = x²+2x+1
  • Producto notable: (x-1)(x+1)=x²-1
  • Racionalizar: 1/√2 · √2/√2 = √2/2

Cálculo básico

  • Límite: limₓ→a f(x) = L cuando los valores de f(x) se acercan a L al acercarse x a a.
  • Derivada: f'(x) = limₕ→0 [f(x+h)-f(x)] / h
  • Regla de la cadena: (f(g(x)))' = f'(g(x)) · g'(x)
  • Regla del producto: (uv)' = u'v + uv'
  • Regla del cociente: (u/v)' = (u'v - uv') / v²
  • Integral indefinida: ∫ f(x) dx = F(x) + C, donde F' = f.
Ejemplos de cálculo:
  • Límite: limₓ→2 (x²-4)/(x-2) = 4
  • Derivada: d/dx(x²)=2x
  • Cadena: d/dx(sin(x²))=cos(x²)·2x
  • Producto: d/dx(x²·x)=2x·x + x²·1
  • Cociente: d/dx((x²)/(x+1))=(2x(x+1)-x²·1)/(x+1)²
  • Integral: ∫2x dx = x² + C

➕ Aritmética Básica

Son las bases para cualquier cálculo:

  • Suma: Añadir cantidades.
  • Resta: Quitar una cantidad a otra.
  • Multiplicación: Sumar un número varias veces.
  • División: Repartir en partes iguales.

🧬 Álgebra

Usamos letras como x para representar números que no conocemos.

Ejemplo:
x + 5 = 12
x = 12 - 5 -> x = 7

🏷️ Polinomios

Clasificación según sus términos:

Monomio: 1 término (Ej: 4x²)

Binomio: 2 términos (Ej: x + 8)

Trinomio: 3 términos (Ej: x² + 2x + 1)

📝 Práctica: Polinomios

Simplifica las expresiones (sin espacios):

1. Simplifica: 2x + 4x + 3

2. Simplifica: 5a + 2b - 2a
